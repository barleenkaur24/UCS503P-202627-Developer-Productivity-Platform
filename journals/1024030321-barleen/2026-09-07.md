## Problems Encountered and Solutions

### Virtual environment
Uvicorn was initially not recognized because the Python virtual environment was not active. Activating `.venv` resolved the issue.

### Repository scanning
The initial scanner included files from `.venv/site-packages`. Ignored-directory handling was added to prevent generated and dependency files from being indexed.

### pytest configuration
pytest initially failed because the repository `pyproject.toml` contained a UTF-8 BOM. The file was rewritten as UTF-8 without BOM while preserving its configuration.

### Windows paths
The scanner returns Windows-style paths using `\`. The tests were updated to account for the platform-specific path format.
